    About me

    I'm a final-year Computer Science & Engineering student at East West University in Dhaka, graduating in December 2026, and an undergraduate researcher in the CSE department under Dr. Farhana Huq.

    I build agents for places where things are hard. Bengali is one of the world's most spoken languages, yet it is low-resource for AI. Farmers need advice where the internet is unreliable. Businesses need data pulled from messy, half-handwritten invoices. So my systems are small enough to run anywhere and honest enough to trust: an offline agentic RAG assistant that fits in 4 GB of VRAM, a hackathon-winning policy assistant, and an extraction pipeline that shows its evidence for every value.

    I care about evaluation that holds up. My latest paper uses significance testing to show how data leakage inflates reported accuracy in solar fault detection. Off the keyboard, I've volunteered with As-Sunnah Foundation during the Bangladesh floods, packing emergency food relief for affected families.

    Projects

    Built end to end, measured, and on GitHub.

    AgriBot

    Team lead, 4 people, final-year capstone

    A fully offline, bilingual (Bengali–English) agentic RAG assistant for farmers. A LangGraph agent decides how to answer each question, a PDF ingestion and vector-indexing pipeline grounds it in agricultural documents, and GPU-optimised Qwen2.5 inference keeps it fast on consumer hardware.

    • 4 GB VRAM is enough
    • 8.5× faster than CPU
    • 100% offline

    Python, LangChain, LangGraph, FastAPI, vector database, Qwen2.5, TypeScript

    Code on GitHub

    Attest

    Solo project

    Verified data extraction from invoices. Every value comes with a confidence score, the source text and its location. Uncertain values go to human review instead of failing silently, and a deterministic validation layer catches dropped rows, misread prices and invented tax IDs.

    • 97.2% field accuracy
    • 6 of 6 injected errors caught
    • 317 ms per document
    • 276 tests, 80% coverage

    FastAPI, PostgreSQL, Redis, SQLAlchemy, React, TypeScript, PyMuPDF, LLM APIs

    Code on GitHub

    EWU AI Engine

    Team lead, 3 people, 1st place

    A university policy assistant built on open-source LLMs, with a PDF ingestion pipeline, semantic vector search and agent-like query routing. Won the LLM-based AI Engine Development Innovation Challenge at EWU Robotic Club.

    Python, LangChain, FastAPI, vector database, open-source LLMs

    Code on GitHub

    AgriBanglaT5 and AgriEnBn

    First author, team of 5

    BanglaT5 (247M parameters) fine-tuned with LoRA to translate farming advice into Bengali without mangling domain terms. I built the 3,232-pair AgriEnBn corpus from legacy Bijoy-encoded government PDFs, NLLB-200 back-translation and LaBSE filtering.

    • +6.1 chrF++ (54.2)
    • 81.8% term accuracy
    • 93.1% negation faithfulness

    PyTorch, Hugging Face Transformers, PEFT / LoRA, NLLB-200, LaBSE

    Model on Hugging Face Code on GitHub
